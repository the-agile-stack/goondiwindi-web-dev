# Goondiwindi Rugby League Football Club – Web Project

A web platform developed for the Goondiwindi Rugby League Football Club as part of the University of Southern Queensland (UniSQ) ICT project.

## 📌 Overview
This project aims to deliver a centralized web platform for the club to streamline administration, share updates, and engage players, supporters, and the local community.

## 🎯 Key Objectives
- **Club Hub:** Publish announcements, match schedules, results, and league standings.
- **Player & Member Info:** Share team information, club events, and registration details.
- **Sponsors:** Provide visibility for local partners and sponsors supporting the club.
- **Administration:** Provide an easy way for club staff to manage and update content.

## 📂 Project Structure
- `src/`: Contains all the HTML markup for the offline functional prototype.
- `assets/`: Contains all static assets (`css`, `js`, `images`).
- `docs/`: Stores technical documentation, UI/UX wireframes, and project plans.
- `tests/`: Contains test plans and feedback reports.

## 🚀 Getting Started
To view the offline functional prototype:
1. Clone this repository locally.
2. Navigate to the `src` folder.
3. Open `index.html` in your web browser. *(Since this is an offline prototype using relative linking, no local web server is strictly required to view the basic structure, though using an extension like VS Code Live Server is highly recommended for development).*
